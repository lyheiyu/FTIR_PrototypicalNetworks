# 本轮具体判断与研究方向

本节解释已完成的九组配对结果。主比较采用最终 session 的 5/10-shot 等权平均；差值单位为百分点，获胜组数按 task/seed 配对统计。所有结论均是 C4 探索性结果，基类 query 复用验证集，实物身份尚未确认。

1. **M1 1-NN 没有稳定超过光谱 1-NN。** 平均总准确率差值为 −0.342，新类平均准确率差值为 −3.155，只在 3/9 组总体获胜。仅胜过旧 M0 不能证明它比简单光谱方法更有价值。

2. **M1 1-NN 也没有稳定超过冻结 PCA64 1-NN。** 总准确率差值为 −0.208，新类差值为 −2.892，只在 2/9 组获胜。两者应继续作为强基线。

3. **D4 迁移尚不能判断。** 107 个锁定坐标在实测范围以外，物理信号表示及实物关系也未确认。没有运行 within-D4 或 C4→D4 识别；不能将阻塞状态写成模型迁移失败，也不能宣称跨数据库泛化成功。简单重采样成同样长度仍会改变物理位置语义，不能绕过网格约束。

4. **原型分类器差异很大，不能笼统说“prototype 有效”。** 欧氏、余弦原型相对 M1 1-NN 分别下降 16.421、17.243；共享 Mahalanobis 下降 3.195，且新类平均下降 14.420，基类高分掩盖了新类不足。收缩 Mahalanobis 则提高总准确率 2.598、新类平均 6.584、Macro-F1 2.763，9/9 组均提升。

| 最终六类准确率（%） | 1-shot | 5-shot | 10-shot | 20-shot |
| --- | --- | --- | --- | --- |
| 光谱 1-NN | 85.393 | 92.828 | 94.898 | 96.198 |
| PCA64 1-NN | 85.198 | 92.710 | 94.748 | 96.067 |
| M1 1-NN | 83.294 | 92.343 | 94.699 | 96.128 |
| M1 SVM | 84.130 | 92.541 | 94.976 | 96.685 |
| 光谱 SVM | 73.994 | 92.880 | 94.789 | 96.412 |
| M1 欧氏原型 | 73.447 | 76.651 | 77.549 | 78.168 |
| M1 余弦原型 | 73.607 | 75.974 | 76.583 | 76.933 |
| M1 共享 Mahalanobis | 85.617 | 89.831 | 90.822 | 91.252 |
| M1 收缩 Mahalanobis | 87.688 | 94.998 | 97.240 | 98.953 |

收缩头相对光谱 1-NN、PCA64 1-NN、光谱 SVM 的 5/10-shot 总准确率增益分别为 **2.256、2.390、2.284**，三种比较均为 9/9 组提升；新类增益分别为 3.430、3.693、3.163。直接配对结果另存 `shrinkage_vs_references_pp.csv`。

在 20-shot 时，基类和两个新类的 exemplar 数均为 20，收缩系数也一致；该头相对光谱 1-NN 仍提高 2.755，说明正向结果并非只出现在基类与新类样本数不对称的条件下。但这还不是对协方差形状、尺度等机制的独立因果分解。

5. **高准确率方案目前没有同时实现小存储。** 最终 5-shot 的数值状态如下，排除 Python/标签对象开销：

| M1 分类头 | 头状态字节（含度量矩阵） | 加上共同编码器后的字节 |
| --- | --- | --- |
| 1-NN | 92,160 | 281,760 |
| 欧氏/余弦原型 | 6,192 | 195,792 |
| 共享 Mahalanobis | 137,264 | 326,864 |
| 收缩 Mahalanobis | 923,696 | 1,113,296 |

普通均值原型的头状态减少约 93.3%，但准确率损失很大。收缩头保存每类 128×128 精度矩阵和一份全局先验，头状态约为 1-NN 的 10 倍，计入共同编码器后约为 4 倍，不能只报告 6 个均值向量来宣称存储节省。

5-shot 新类注册（包含冻结编码、排除预处理）为收缩头约 3.574 ms、M1 1-NN 约 3.608 ms，差距很小；头本身更新约 0.317/0.352 ms。缓存 query 上的预测约 0.396/0.349 ms，收缩头反而略慢。当前支持“无需重拟合全局分类器、只更新到达类”，不支持“明显更省内存、更快端到端推理”。查询编码尚未计入这些预测数字。

6. **困难类主要是 HDPE 和 PS，PVC 也需要关注。** 作为新类的 5/10-shot 平均 recall，M1 1-NN 的 HDPE/PS/PVC 为 73.34/77.86/82.50%，收缩头提高到 85.01/87.87/92.93%。具体每类 precision/recall/F1 和任务混淆矩阵均已保存。

旧类参数不改也不等于旧类分数不下降。第一新类在 Session 1→2、同一份 query 上，收缩头平均下降约 7.520 个百分点，M1 1-NN 下降约 7.759；没有消除新增类别带来的竞争。不能将不同 session 的 current_novel 差值直接当遗忘，因为对应类别不同。

7. **目前没有证据证明必须引入新 prototype-learning objective。** 固定的收缩度量在没有梯度训练的情况下已经改善成绩，说明至少一部分问题可通过类度量处理；普通均值原型的失败说明当前表示不自动提供良好的均值距离几何，但并不能唯一归因于缺少某种训练损失。

下一阶段建议按以下顺序推进，当前不额外运行或改模型：

- 先补充覆盖锁定物理网格、信号语义明确、实物身份可审计的外部数据。D4 当前版本不适合本轮冻结 M1 的有效迁移测试。
- **补充 PCA64 + 同一收缩 Mahalanobis 的匹配对照**，只用合法基类数据确定设置，以分离表征与分类头贡献。当前“M1 + 收缩头胜过光谱/PCA 1-NN”是组合方案优势，不能单独归因于神经编码器，因为两边的分类头不同。
- 优先研究类协方差的共享或等价低秩存储/计算，保留冻结 M1 和局部注册机制，检验能否保留当前准确率并缩小矩阵状态。该建议尚未实现，也未在当前新类 query 上搜索新参数。
- 只有上述对照和独立验证仍表明均值原型几何是核心瓶颈时，再预先设计新的基类训练目标对照。本轮不新增 ProtoNet、SupCon、增强或自定义损失。
