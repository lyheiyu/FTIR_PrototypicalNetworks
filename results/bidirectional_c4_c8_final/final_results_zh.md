# C4/C8 双向跨分辨率 few-shot 增量：最终结果

本轮只使用 C4/C8。3 任务 × 3 种子；每对 C4、C8 模型同初始化、同训练组顺序、同 60 epoch 预算；新增类阶段 encoder 始终冻结。主要指标先在每个任务/种子内平均 200 次重复与 5/10-shot，再汇总配对值。

**研究边界：这是记录组隔离的探索性评价，不是已验证实物独立、也不是全新未查看的确认性外部测试。** 两侧都重新训练是为了让 query 组不参与训练或 checkpoint 选择；没有改架构、loss、增强或搜索超参数。

## 主要发现

收缩相对完整类协方差的平均 Accuracy 更高的设置为 A, B, E, F，更低的设置为 C, D；因此应按来源/参考库条件陈述优势，不能只挑一个方向。
四个跨来源设置 C/D/E/F 中，PCA64＋收缩减 M1＋收缩的平均差值范围为 +2.205 到 +12.829 pp。本轮平均结果未建立神经网络表示相对该 PCA 控制的性能优势。
不含全局 covariance prior 的 M1 1-NN 对照中，两方向参考库对齐效应的平均绝对量为 11.598 pp，匹配目标支持/查询时 encoder 来源效应的平均绝对量为 0.989 pp。本协议下参考库来源的条件效应量级更大。 这是所覆盖六设置的条件比较，不是完整 factorial 的唯一因果分解。

## 双向迁移与来源因素

- M1 Full：C4→C8 为 81.902%，相对同源 A 变化 -8.990 pp；C8→C4 为 82.988%，相对同源 B 变化 -7.933 pp。改用 target base 库的收益 E−C=+8.977 pp、F−D=+7.629 pp；目标支持/查询完全匹配时，来源变化 E−B=-0.043 pp、F−A=-0.275 pp。
- M1 Shrinkage：C4→C8 为 77.246%，相对同源 A 变化 -17.903 pp；C8→C4 为 75.282%，相对同源 B 变化 -20.561 pp。改用 target base 库的收益 E−C=+17.182 pp、F−D=+19.395 pp；目标支持/查询完全匹配时，来源变化 E−B=-1.415 pp、F−A=-0.471 pp。
- PCA64 Shrinkage：C4→C8 为 89.251%，相对同源 A 变化 -8.014 pp；C8→C4 为 88.112%，相对同源 B 变化 -9.733 pp。改用 target base 库的收益 E−C=+7.730 pp、F−D=+8.771 pp；目标支持/查询完全匹配时，来源变化 E−B=-0.864 pp、F−A=-0.382 pp。
- M1 1-NN：C4→C8 为 80.981%，相对同源 A 变化 -12.464 pp；C8→C4 为 81.252%，相对同源 B 变化 -12.710 pp。改用 target base 库的收益 E−C=+12.602 pp、F−D=+10.594 pp；目标支持/查询完全匹配时，来源变化 E−B=-0.379 pp、F−A=-1.599 pp。
M1 Full 的绝对方向比较：本轮平均 C8→C4 更高，D−C=+1.086 pp；逐任务一致性仍需看配对明细。
M1 Shrinkage 的绝对方向比较：本轮平均 C4→C8 更高，D−C=-1.964 pp；逐任务一致性仍需看配对明细。

C−D 是双向绝对准确率差，(C−A)−(D−B) 是相对于各自同源基线的退化不对称，两者不能混同。对应的每个任务/种子/shot 配对值在 paired_comparisons.csv。
E−B 和 F−A 在 M1 1-NN 与独立完整类协方差中不使用全局 base prior，反映固定分类公式下的 encoder 来源变化；M1/PCA 收缩方法还包含来源 prior 的变化，不能统称纯 encoder 因果效应。E−C、F−D 则固定 encoder 和适用的 source prior，改变的是同组 base 参考光谱来源。原谱 A=F、B=E 指标必须精确一致，已作为自动检查。

## 支持的结论与限制

可以检验：在共同波数网格、已知重复/记录组隔离、固定训练预算下，跨 C4/C8 来源的分类表现与方向不对称；在不更新 encoder 的情况下新增两类的效果；改用目标来源 base 参考库的影响。
不能声称：已完成独立仪器或实物独立的确认性泛化；同记录编号必然代表相同物理采集；历史已查看数据上的结果是全新未触碰测试；固定 nominal ridge 意味着 PCA64 与 M1-128 的相对正则完全相同。
原流程在原生采样点上先做 airPLS 再插值；相同数值参数并不保证在不同原生点密度下具有相同的物理平滑尺度。方向差异包含这一固定预处理条件，不能纯归因于仪器光学分辨率，也未确认物理信号为吸光度或透射率。
本轮结束当前论文的实验开发。应按实际正负结果写作，不再据 query 结果继续更换结构、loss 或调参。
