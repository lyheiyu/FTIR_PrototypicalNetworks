# C4/C8 第一轮正式结果分析

本报告分析 results/fewshot_main，不包含 smoke 结果。配置：两个数据集、3 个 seed、1/5/10/20-shot、每个设置 200 个 episode、每类 15 个 query。每个数据集/seed 的监督 encoder 使用六类训练数据；K-shot 指测试 episode 的真实 support 数，不是 encoder 训练的全部标注预算。本轮没有 EMSA、跨分辨率训练测试或未见类别实验。

## 完整性检查

- seed_metrics.csv 有 144 行，等于 2×3×4×6，无重复设置。
- 所有已保存 episode 的 support/query 都位于该 seed 的 test split，且两者不重叠；每类数量符合协议。
- 每个 seed/shot/method 的累计 CM 计数为 18000，即 200×6×15；这是 query 出现次数，不是 18000 个独立实物。
- 四种距离在 1-shot 的逐样本预测完全一致，符合零类内协方差下的退化预期。
- 保存的 fewshot_benchmark.py、utils.py 源码快照与当前版本一致。

## 可以得出的结论

1. 在当前固定 encoder 上，每类完整 Mahalanobis 相比欧氏距离有稳定收益。C4 在 5/10/20-shot 分别提高 11.26/16.87/19.98 个百分点；C8 分别提高 11.67/18.14/23.15 个百分点。所有三个 seed 在这些设置下的提升方向一致。
2. 完整类条件协方差相比对角方案表现更好，支持保留完整协方差作为主要消融项。不过这不能单独证明原始光谱中某种特定物理关联导致了提升。
3. 每类独立协方差相对于共享协方差的额外收益有限且依赖 shot。C4 的 5-shot 三个 seed 均较差，均值低 1.96 个百分点；10/20-shot 只高 0.19/0.54。C8 的 5/10/20-shot 分别高 0.02/1.16/1.42。只有 C8 20-shot 的三个 seed 都优于共享协方差。
4. Raw SVM 在全部数据集/shot 设置中最好，Raw KNN 在 5/10/20-shot 也优于每类完整 Mahalanobis。本轮不能宣称提出的方法全面优于传统分类器。SVM/KNN 与 encoder 方法的信息预算不同：前者只用当前 support，后者还使用监督预训练数据；这也不支持把主方法的劣势解释为标注更少。
5. Macro-F1 的趋势与 Accuracy 一致。每类完整 Mahalanobis 在 C4 5/20-shot 为 77.02/89.63%，C8 为 79.11/91.58%；对应 SVM 为 86.30/95.88%、90.40/98.24%。

## 稳定性与实现层面的观察

- 主方法 C4 5-shot Accuracy 为 77.71±4.60%，C8 为 79.65±0.97%；此处 ± 是三个 seed 均值的样本标准差，不是 95% CI。
- 三个 seed 不足以对共享与每类协方差的小差距作强统计结论；200 个重复 episode 不能替代 200 次独立训练。
- 六次 encoder 训练都达到 60 轮上限；最低 val_loss 出现在第 57–60 轮附近，最佳轮训练 Accuracy 约 86–90%。这是进一步检查训练预算和表征的理由，但不能保证加轮数必然提高性能。
- 5-shot 时所有 seed 的每类完整协方差均选择正则网格上边界 0.01。可能需要更大的 ridge 或收缩协方差，应只通过 validation 检验，不按当前 test 结果选参数。
- 原始 embedding 上欧氏距离随 K 增大改善较少，而原始谱 SVM 很强，提示首先检查 encoder 的表征与原型距离是否匹配；目前不能仅凭结果确定是特征范数、网络架构还是训练目标造成。
- 1-shot 时 3-NN 的三个邻居必来自三个不同类别，普通投票必然打平，由最近邻实现的类别排序规则决定结果。该行不适合当作正常 KNN 能力的证据，应另做明确的 1-NN 基线，或在后续预先规定适合 K 的邻居数。该问题不影响四种距离之间的比较。
- C8 的均值较高并不能证明低分辨率本身更好：两个文件的样本组成、去重后的数量、随机划分和 encoder 均不同。

## 下一轮的优先级

1. 保留本轮为 V1，不覆盖。当前最有力的结论是“在固定表征上，完整 Mahalanobis 明显优于欧氏；每类适配的额外收益依赖 support 数量”。
2. 在相同冻结 encoder 上增加 embedding-SVM、embedding-1NN，另保留 raw-SVM/raw-1NN，区分表征问题与分类规则问题。L2 特征归一化及正则范围也只在 validation 比较。
3. 在 validation 上比较共享/每类协方差的收缩方案，重点改善 5-shot 的高方差；如设计为新方法，需明确公式并与当前版本独立标注。
4. 通过 validation 决定是否延长训练或使用原 MCCV2 backbone。当前小型 CNN 是新基准表征，不是旧 H5 的逐层复现；在评估旧 backbone 时同样需要干净重训。
5. 增加 seed 3、4 作为稳定性检查，再接 EMSA。不要只保留方法表现好的 seed 或 shot。
6. EMSA、跨分辨率、未见类别仍需单独实验，不可从本轮结果推断。
