# C4 v2 输入方法开发实验结论

## 完整性与范围

- COMPLETE 标记存在；9 候选×3 seed×4 shot×100 screen episode，共 10800 条指标，无重复设置。
- 1260 个 tune/screen episode 的 support/query 不重叠，所属开发 pool 正确。
- 仅 PET、PP、PS、PVC：1653 条去重谱。HDPE/LDPE 完全排除于本次筛选。
- 信号处理为 legacy：原 profile 反转、native airPLS、逐谱 maxabs、再对齐。不是已经验证的物理吸光度流程。
- groups=null，属于数值去重后的开发筛选，不是严格实物分组的最终测试。

## 1. 分类差异非常小，不能把排序当作明确胜负

Accuracy（%，三 seed/episode 均值）：

| 方法 | 点数 | 1-shot | 5-shot | 10-shot | 20-shot |
| --- | ---: | ---: | ---: | ---: | ---: |
| Native | 3736 | 72.05 | 87.66 | 92.22 | 96.26 |
| Linear / factor2 | 1868 | 72.04 | 87.53 | 92.22 | 95.96 |
| Cubic / factor2 | 1868 | 72.05 | 87.54 | 92.23 | 95.96 |
| PCHIP / factor2 | 1868 | 72.05 | 87.53 | 92.23 | 95.96 |
| Bin mean / factor2 | 1868 | 72.06 | 87.54 | 92.22 | 95.94 |
| Linear / factor4 | 934 | 72.06 | 87.72 | 92.22 | 95.27 |
| Cubic / factor4 | 934 | 72.05 | 87.72 | 92.24 | 95.26 |
| PCHIP / factor4 | 934 | 72.05 | 87.72 | 92.24 | 95.26 |
| Bin mean / factor4 | 934 | 72.05 | 87.69 | 92.27 | 95.16 |

同一网格上，三种点插值的最大 Accuracy 均值差只有约 0.022 个百分点。5-shot Macro-F1 的 seed 标准差约 1.5–1.8 个百分点，远大于这些均值差；这不构成统计显著或等价检验结论，但不支持强调某种插值分类明显优越。

预先按 5/10-shot Macro-F1 排序，cubic_factor_4 排第一；相对同网格 Linear 的分数优势约 0.014 个百分点。这是开发排序中的近似并列，不能称为已证明的最佳方案。

## 2. 网格选择比点插值方法的影响更值得关注

- Native：约 0.9642 cm^-1 采样间隔、3736 点。
- factor2：约 1.92898 cm^-1、1868 点，输出矩阵字节数为 native 的一半。
- factor4：约 3.86003 cm^-1、934 点，输出矩阵字节数为 native 的四分之一。

5/10-shot 中各网格接近；20-shot 的 Cubic 从 native 96.26%，降至 factor2 的 95.96%、factor4 的 95.26%。factor4 相对 factor2 低约 0.69 个百分点，不能只因为其 5/10-shot 排序略高就忽略该取舍。

但差距不能全部归因于不可逆信息损失：维数会影响向量范数和线性 SVM 的有效正则化；部分调参选中 C 网格上界，只有 5 个 tune episodes。若扩大范围，应继续只在开发数据进行，并完整记录，不能拿最终 novel query 回选。

这些采样间隔不代表仪器实际光谱分辨率。

## 3. 光谱保真：Cubic 在本次遮点任务上更好

12 条参考谱（PET 3、PP 4、PS 2、PVC 3）的原始点遮点重建平均 RMSE：

| 点插值 | Raw-intensity RMSE | NRMSE |
| --- | ---: | ---: |
| Linear | 0.062505 | 0.003470 |
| Cubic | 0.009985 | 0.000538 |
| PCHIP | 0.028802 | 0.001588 |

Cubic 的 RMSE 约为 Linear 的六分之一，但这没有转化为更高的 SVM 分类精度。它只验证观测点重建，不等于恢复真实仪器分辨率。

注意：目前该遮点实验直接从保留的原始点重建隐藏点，没有经过候选目标网格，因此同一种方法 factor2/factor4 的 RMSE 相同是设计结果，不能用它判断网格之间的保真差异。

factor2 的平均全谱主峰位置差约 0.46 cm^-1，factor4 约 1.28 cm^-1；当前参考样本在不同方法下选到了相同目标峰点，不能据此推断所有化学特征峰一致。Cubic 有小幅全局范围过冲，factor2 参考谱平均 0.000269、最大 0.000939（legacy 归一化强度单位）。这也不等同于完整局部虚假峰计数。

Bin mean 面积误差接近浮点精度，是算法相对分段线性参考的积分定义保证，不是独立证明物理光谱更准确；它不参加点值重建 RMSE 排名。

## 4. 成本：Linear 的重采样快，但总流程收益有限

1653 条谱的 factor2 harmonization：Linear 0.125 s、Cubic 0.833 s、PCHIP 0.502 s、Bin mean 0.517 s。独立的 native 预处理约 14.10 s。

因此 Linear 在这次单次插值计时中约为 Cubic 的 6.7 倍速度，但不能声称完整识别流程快 6.7 倍；整体还包含基线、模型和分类。计时未做重复暖机统计，矩阵字节数也不是进程峰值内存。

## 5. 类别结论没有因换插值明显改变

5-shot 的 Cubic factor2 recall：PET 100%、PP 89.33%、PS 81.18%、PVC 79.64%。Linear factor2 对应为 100%、89.33%、81.18%、79.62%。

主要混淆仍是 PVC→PS（约17.6%）、PS→PP（约10.8%）、PP→PS（约9.1%）。插值变化没有解决这组分类混淆。这里没有测试更难的 HDPE/LDPE，不能据此得出它们不受影响的结论。

## 6. 对后续研究的决策建议

1. 目前没有证据表明只把 Cubic 换成 PCHIP 就能解决旧 Encoder 的性能差距；也没有证据证明插值方法普遍等价。
2. 暂保留 Cubic factor2 为保真取向候选，Linear factor2 为简单/快速候选。不是最终锁定，也不是推翻预设主指标的事后冠军；它们是供下一步匹配验证的少量配置。
3. 暂不把 factor4 或 Bin mean 的极小开发排名优势写成新方法收益。先补更多按类覆盖的化学峰诊断和允许开发数据上的稳定性分析。
4. 必须将共同范围、点数和完整 grid 向量显式锁定后，才能做跨 C4/C8 的同网格比较。C8 的原生间隔不同，直接复用 factor2 会产生与 C4 不同的物理网格。
5. 信号单位和 specimen 身份仍待确认；保留 legacy 分支，物理转换作为另一个版本比较，不覆盖历史数据。
6. 在相应合法开发任务中确定少量候选后，才用同架构/同预算重训匹配输入的 encoder。不能把新网格或新信号变换直接喂旧权重，将下降解释为插值优劣。

现阶段适合论文中的表述：在 C4 四基础类的 legacy 开发协议下，三种点插值对线性 SVM 的性能影响很小；Cubic 在有限参考谱的原始点重建误差较低，Linear 的插值开销更小，较粗网格在高 shot 时存在精度取舍。该结果尚不构成未见类别、真实跨分辨率或跨设备泛化证据。
