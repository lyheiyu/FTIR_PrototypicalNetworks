# C4 冻结 M0/M1：4+1+1 增量评估结果

已完成三任务 × 三种子、1/5/10/20-shot、每 shot 200 个配对 episode。复用架构比较的十八个 M0/M1 checkpoint、原始样本角色、1868 点预处理及新类 support/query，编码器训练调用为零。旧实现的分类头、评分和混淆矩阵工具直接复用；旧的重新划分与训练入口未改动。

## 结论

M1 相比 M0 的优势在六类增量竞争中保持：最终 session 的 5/10-shot 平均总准确率，SVM 提升 **14.24 个百分点**，1-NN 提升 **12.67 个百分点**，两者均在九组配对中全部提升。

M1 与光谱 SVM 的总体成绩接近，不能据此宣称新类识别全面超过光谱基线。5/10/20-shot 时 M1 SVM 的已引入新类平均准确率分别为 **81.54/89.39/95.09%**，光谱 SVM 为 **86.06/92.42/96.65%**。M1 的基类成绩更高，部分抵消了新类差距。1-shot 则不同：M1 SVM 的新类平均准确率为 55.55%，光谱 SVM 为 46.17%；该结果仅适用于此次锁定的 exemplar 和历史 C 选择条件。

## 保留旧类的变化

比较同一份第 5 类 query 在第一次和第二次注册后的准确率，5/10-shot 平均下降：M0 SVM 10.78、M1 SVM 6.20、光谱 SVM 5.76 个百分点；M0/M1 1-NN 分别下降 10.47/7.76 个百分点。逐配对变化见 `retention_deltas.csv`。

编码器权重完全没变，这里的下降发生在新增类别后的分类竞争中，不能解释为编码器参数发生遗忘。也不能直接用两个 session 的 current_novel 差值衡量遗忘，因为那是两个不同的新类。

## 局部注册与完整重拟合成本

以下是 5-shot 每次新类到达的平均毫秒数，跨九组及 Session 1/2 平均。局部注册包含冻结编码 K 条输入及新类入库，排除共享逐行预处理。完整更新时间另包括已见类库整理及分类器重拟合/索引准备。

| 方法 | 局部注册 ms | 完整 SVM 重拟合 ms | 1-NN 索引准备 ms | 合计更新 ms |
| --- | --- | --- | --- | --- |
| M0 SVM | 5.017 | 1.002 | — | 6.168 |
| M1 SVM | 4.506 | 0.941 | — | 5.509 |
| M0 1-NN | 5.017 | — | 0.370 | 5.447 |
| M1 1-NN | 4.506 | — | 0.367 | 4.934 |
| 光谱 SVM | 0.013 | 2.711 | — | 3.173 |

M1 的低维特征降低 SVM 重拟合成本，但新类仍需要编码，所以这轮 5-shot 完整更新时间没有快于光谱 SVM。若只报 0.941 ms 的 SVM 拟合，就会遗漏约 4.506 ms 的注册成本。

“完整 SVM 重拟合”是在全部当前保留 exemplar 上重新拟合多类线性 SVM，Session 0/1/2 为 80、80+K、80+2K 行；不是完整历史原始数据上的重放实验。所有分类头的 exemplar 索引相同，每个基类固定 20 条，每个已到达新类保留 K 条，旧 support 不丢弃、不重抽。

1/5/10/20-shot 全部成本在 `cost_summary.csv` 和 `local_registration_summary.csv`；逐次成本见 `metrics.csv`、`registration_costs.csv`。编码计时是预热后的实际 support 重执行，评分用原缓存嵌入并校验一致性。没有新编码器训练；历史 encoder 训练成本属于父实验，不计入注册成本。预测时间另记，不含缓存 query 的编码。以上为同机 CPU 微基准，不代表完整部署吞吐。

## 审计、图和结论边界

三项专项测试和实际小规模配对运行通过。`parent_reuse_audit.json` 通过了九组、21,600 个 session-episode、十八个 checkpoint 的核查：新类 support/query 与父实验逐条一致，数据角色正确，没有 support/query 交叉，父输入和 checkpoint 文件未改变。共保存 108,000 行分类器评估指标。`protocol_audit.json` 还检查旧 support/query 在新增 session 中持续保留，支持/query 数正确，编码器权重哈希不变。

`figures` 中有四个 shot 的 session 曲线，以及三个任务在 5/20-shot 的最终六类混淆矩阵，PNG/PDF 和计数 CSV 均已生成。矩阵累计的是重复 query 出现次数，不是独立实物数量；由累计矩阵重算的 F1 也不一定等于先按 episode 计算后平均的 F1。

必须保留三点限制：

1. 基类 query 来自原 base_validation，之前参与了 checkpoint/C 选择；基类及总体指标不是独立测试成绩。在复用原划分和 checkpoint、不重训的约束下，本轮无法补出全新的独立基类测试集。
2. M0/M1 编码器曾使用完整 base_train 学习，光谱 SVM 没有历史表征学习阶段。当前分类头 exemplar 预算匹配，全部历史监督机会并不相同。具体条件见 `data_access_conditions.md`。
3. C4 新类已用于此前探索，实物分组尚未验证。本轮支持保留固定 M1 做后续验证，不能充当独立数据上的确认性结论。

本轮没有新增编码器、损失、增强，也没有通过新类 query 重新选择 C、类别权重或其他超参数。后续应先处理独立验证与数据身份审计；本报告不据现有新类分数继续搜索模型。
